Sweet Top Bites ordering system

Prototype user manual

How the online shop, counter POS and owner dashboard work across all four branches.

1. What's in the prototype

Area Who uses it What it does
Online shop Customers Pick a branch, browse that branch's menu and prices, order for delivery or pickup, pay online, track past orders.
Counter POS Cashiers Ring up walk-in sales at any of the four branches, take cash or mobile money, see live stock per branch.
Branch manager dashboard Branch managers The same dashboard as the owner's, but locked to that manager's own branch — its revenue, orders, inventory and profit & loss only.
Owner dashboard Owner Everything a manager sees, for every branch at once or filtered to one — plus adding new menu items and restocking any branch from one screen.

Every sale, online or at the counter, lands in the same order list and reduces the same stock, so every dashboard always reflects both.

2. The four branches

Each branch has its own hours, contact number, stock, and — importantly — its own prices and its own delivery availability. A&C Corner, Legon and Madina run full hours and offer delivery. Adabraka is a weekday lunch spot with shorter hours and pickup only; delivery is switched off there rather than removed from the code, so it can be turned back on the moment they add a rider for that branch.

4. Walkthrough — the customer's side

  1. Choose a branch from the bar under the header. The menu, prices and whether delivery is offered all update to match.
  2. Browse and add to basket. Sold-out items show Sold out instead of an Add button.
  3. Checkout. Sign in or create an account, choose delivery or pickup (delivery is hidden if the branch doesn't offer it), and pay by mobile money or card — online orders are always paid before pickup or delivery.
  4. My orders, in the header once signed in, lists that customer's past orders.

5. Walkthrough — the counter POS

Sign in as the cashier, pick the branch at the top, and tap products to build the ticket. Take cash (with a change calculator) or MoMo, then Complete sale — stock at that branch drops immediately and the sale appears on the dashboard.

6. Walkthrough — the owner and manager dashboards

Sign in as the owner to see every branch, filterable by branch (all four, or one at a time) and by date range, using the presets or a custom range. Sign in as a branch manager and the same dashboard opens already locked to that one branch — the branch switcher is hidden, since a manager only needs their own numbers. In both cases the headline figures, the revenue chart, the payment and channel breakdowns, the branch mix, top sellers, inventory and profit & loss estimate all respond to the filters together.

7. Adding inventory

The Inventory panel on the dashboard lists every product's stock, per branch. Underneath it, Add stock or a new item lets you either top up an existing product (pick it, pick a branch — or "All branches" if you're the owner — and a quantity) or introduce a brand-new menu item (name, category, price, cost and a starting stock). A branch manager can only add stock or new items to their own branch; the owner can do it for any branch, or all of them at once. New items appear on the shop, the counter POS and every dashboard immediately.

8. Connecting Paystack

The prototype ships with a simulated Paystack checkout so it works anywhere. To use a real Paystack test account, open index.html, find the CONFIG block near the top:

const PAYSTACK_PUBLIC_KEY = '';

and paste in your pk_test_... public key. Never put the secret key (sk_test_/sk_live_) in this file — it belongs on a server, not in a page anyone can view. See the full explanation in the Crème Bakery manual if you need a refresher on why.

9. Where the data lives

This is a static page with no server, so accounts, orders, stock and any items added from the dashboard are kept in the browser's own storage on the device being used — they don't sync between devices, and the 90 days of sample history regenerates each day. Reset demo data in the footer clears everything back to the sample state.

10. What the full build adds

A shared database across every branch and device, real staff accounts and permissions managed by the owner (including creating manager logins for new branches), Paystack payment verification on the server, WhatsApp order notifications, printable receipts, ingredient-level stock, and richer inventory tools such as low-stock alerts and supplier orders.
